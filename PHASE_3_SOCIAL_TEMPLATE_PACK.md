# Wild & Well — Reusable Social Template Pack

This file turns the 30-day copy in `PHASE_2_LAUNCH_PACK.md` into repeatable production templates. It deliberately contains no invented audience, revenue, performance or health-outcome claims.

## Brand rules

- Tone: calm, practical, UK-focused, evidence-led.
- Principle: problem first, no-spend steps second, products only when useful.
- Never use fear imagery for resilience content.
- Never imply a product treats or cures a medical condition.
- Never put a raw affiliate URL in a social post; route to Wild & Well.
- Keep the Wild & Well name/logo in a consistent small footer area rather than dominating the useful content.

## Template A — Instagram/Facebook education carousel

**Canvas:** 1080 × 1350 px per slide.
**Slides:** 5.

1. Hook: 5–9 words. Example: `Purifier or dehumidifier?`
2. `What problem are you solving?` + one-sentence distinction.
3. Practical/no-spend check.
4. When a product may help + one buying criterion.
5. `Learn first. Buy second.` + `wild-and-well.store`.

**Caption:** use the matching day in `PHASE_2_LAUNCH_PACK.md`.
**Instagram destination:** profile link with `utm_source=instagram&utm_medium=organic_social&utm_campaign=phase3_launch&utm_content=dayXX_topic`.
**Facebook destination:** paste the same page URL directly with Facebook UTM parameters.

## Template B — Instagram/Facebook static card

**Canvas:** 1080 × 1350 px.
**Layout:** short headline top third; one supporting sentence centre; Wild & Well footer.

Approved recurring headlines from the launch pack:
- `Healthier home. Healthier habits. Less hype.`
- `Sleep products come second.`
- `Water filter price ≠ running cost`
- `Room size • filter cost • noise`
- `Use up. Replace thoughtfully.`
- `72 hours. Boring essentials first.`

Do not add statistics unless the exact statistic has been source-checked for that post.

## Template C — Pinterest evergreen Pin

**Canvas:** 1000 × 1500 px.
**Layout:** topic eyebrow; 6–11 word search-intent headline; simple visual; bottom strip `Practical UK guide • Wild & Well`.

Use the exact Pin title, description, board and destination from the 30-day launch pack. Destination should include:
`utm_source=pinterest&utm_medium=organic_social&utm_campaign=phase3_launch&utm_content=dayXX_topic`

## Template D — Reel/TikTok/Short

**Canvas:** 1080 × 1920 px.
**Length:** aim for 20–35 seconds unless the script needs more time.
**Safe area:** keep important text away from the extreme top/bottom and right-side UI.

Sequence:
- 0–2 sec: exact hook from launch pack.
- 2–8 sec: define the problem.
- 8–20 sec: 2–3 practical points.
- 20–30 sec: one next step.
- End frame: `Read the practical guide • Wild & Well`.

First reusable hooks:
- `The most underrated fitness equipment? Your front door.`
- `You do NOT need to throw your whole house away to live lower-tox.`
- `A water filter cannot filter water you don't have.`
- `Ask this before buying any wellness product.`

Use native captions. Avoid fast flashing transitions. A phone-shot voiceover/B-roll format is acceptable; production quality should not delay publishing useful information.

## Template E — Checklist carousel

**Canvas:** 1080 × 1350 px.
**Slides:** 6.

1. `Before you buy...`
2. Define the problem.
3. Check what you can change for free.
4. Check sizing/capacity/fit.
5. Check ongoing cost/maintenance.
6. `Compare only when the job is clear.`

Works for: water filtration, air purifiers, dehumidifiers, sleep products and movement equipment.

## Exact platform paste map

### Instagram
`+` → Post or Reel → select the prepared asset → **Caption** = matching Instagram caption in launch pack → publish/schedule. For the destination: Profile → Edit profile → Links → use the current campaign destination with Instagram UTM parameters. Do not paste a long non-clickable URL into every feed caption.

### Facebook
Meta Business Suite → Create post → select Wild & Well Facebook Page → upload asset → **Post text** = matching Facebook/Instagram caption → add full destination URL with Facebook UTM parameters → Schedule.

### Pinterest
Create → Create Pin → **Image** = 1000×1500 asset → **Title** = launch-pack Pin title → **Description** = launch-pack description → **Link** = destination + Pinterest UTM → **Board** = launch-pack board → Publish/Schedule.

### TikTok
Create/upload → 1080×1920 video → use the launch-pack script as voiceover/on-screen sequence → enable/edit captions → **Description** = supplied short-form caption. Send people to the Wild & Well profile/site; do not use raw affiliate links.

### YouTube Shorts
Create/upload Short → **Title** = hook rewritten as a natural title → **Description** = one-sentence summary + destination with YouTube UTM → verify captions → Publish/Schedule.

## Production order

Do not attempt 90 bespoke designs before launch. Produce a small reusable system, then change headline/visual/topic:

1. One carousel master.
2. One static-card master.
3. One Pinterest master.
4. One vertical-video master/end card.
5. One checklist carousel master.

This keeps the campaign visually consistent and makes the 30-day pack realistic to publish.
